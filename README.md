# OpenFloorball Coach Platform

## Die offene digitale Plattform für Floorball-Trainer, Vereine und Spieler

---

# Über das Projekt

OpenFloorball Coach ist eine Open-Source-Plattform zur digitalen Unterstützung von Floorball-Training, Taktikentwicklung und Wissensaustausch.

Die Plattform verbindet:

* digitales Taktikboard
* Trainingsplanung
* Übungsbibliothek
* Teamarbeit
* Floorball-Wissen

mit modernen Prinzipien:

* Datenschutz
* offene Standards
* digitale Selbstbestimmung

---

# Vision

Floorball-Trainer sollen einfache, professionelle Werkzeuge erhalten, um:

* Spielideen verständlich zu machen
* Training besser vorzubereiten
* Wissen innerhalb von Vereinen zu bewahren
* gemeinsam voneinander zu lernen

---

# Warum OpenFloorball?

Viele digitale Sportwerkzeuge sind:

* geschlossen
* teuer
* nicht auf Floorball spezialisiert
* abhängig von einzelnen Anbietern

OpenFloorball verfolgt einen anderen Ansatz:

Eine offene Plattform, die der Community gehört.
