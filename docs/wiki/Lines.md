# 🥍 Lines (Sturm-/Defensivreihen)

Eine **Line** gruppiert mehrere Spieler eines Boards zu einer taktischen
Formation, z. B. eine Sturmreihe oder eine Special-Teams-Formation
beim Powerplay.

## Line anlegen

Im unteren Tab-Menü unter "Lines":

- **Name** (frei wählbar)
- **Typ**: Sturm (offense), Verteidigung (defense), Special Teams
  (special)
- **Farbe**: zur visuellen Unterscheidung auf dem Feld
- **Spieler zuweisen**: beliebige Spieler des aktuellen Boards

Maximal **10 Lines pro Board**.

## Aktive Line

Nur eine Line pro Board kann gleichzeitig "aktiv" sein. Die
zugewiesenen Spieler werden dann auf dem Spielfeld farblich hervorgehoben
– praktisch, um während einer Trainingsbesprechung schnell zu zeigen,
welche Spieler zusammen auf dem Feld stehen sollen.

## Verwaltung

- Lines umbenennen, Farbe/Typ ändern, Spieler hinzufügen/entfernen
- Line löschen (Spieler selbst bleiben im Board erhalten, nur die
  Gruppierung verschwindet)

## Verwandt

- [Kader](./Kader.md) – Spieler zentral pflegen, dann einer Line zuweisen
- [Formationen](./Formationen.md) – ganze Startaufstellungen als
  Vorlage speichern (anderes Konzept als Lines: Formationen sind
  Positionen, Lines sind Gruppierungen bestehender Spieler)
