# 📚 IFF Regelwerke & Spielfeld-Spezifikationen

Dieses Dokument fasst die relevanten IFF-Regeln für FloorForge zusammen.
Offizielle Quelle: [IFF Offizielle Regeln](https://floorball.sport/game/rules/)

---

## 🏒 Spielfeld-Typen

### 1. Großfeld (Standard IFF)
- **Maße:** 40m x 20m
- **Bande:** 50cm hoch, IFF-zertifiziert
- **Spieler:** 5 Feldspieler + 1 Torwart pro Team
- **Tormaße:** 160cm x 115cm (B x H)
- **Torwartbereich:** 4m x 5m
- **Torhüter-Fläche:** 2.5m x 1m

### 2. Kleinfeld
- **Maße:** ca. 20m x 14m (variabel)
- **Spieler:** 3 Feldspieler + 1 Torwart pro Team

### 3. 3v3 (IFF 3v3 WFC 2026)
- **Maße:** 22m x 11m (Standard), min. 18m x 9m, max. 24m x 12m
- **Spieler:** max. 10 Spieler pro Team (max. 9 Feldspieler + max. 2 Torwärter)
- **Torwartbereich:** 1.5m x 2.5m

### 4. Street Floorball
- **Maße:** ca. 25m x 15m (variabel, Hay-Bales als Begrenzung)
- **Tore:** 2m x 4m
- **Kein Torwart** erforderlich

## ⚽ Ball-Spezifikationen (IFF)

- **Farben erlaubt:** Eine Farbe (nicht-fluoreszierend)
- **Offizielle Wettkampffarben:** Weiß oder Rot (für Ligabetrieb)
- **Sonstige Farben:** Mit Ausnahmegenehmigung durch IFF/nationale Föderation möglich
- **Gewicht:** 23 ± 1 Gramm
- **Der offizielle IFF-Ball (aktuell):** Unihoc Dynamic ("Hot Orange" / Apricot für internationale Wettbewerbe)
- **Nationale Föderationen** können andere Farben als Weiß, Vanille oder Rot genehmigen

---

## 👕 Team-Farben

- Heimteam und Auswärtsteam müssen unterscheidbare Farben tragen
- In FloorForge konfigurierbar in den Einstellungen

## 🎯 Positionen (Großfeld)

| Position | Abkürzung | Beschreibung |
|---|---|---|
| Torwart | TW | Verteidigt das Tor, kein Schläger |
| Rechter Verteidiger | RV | Defensive Absicherung rechts |
| Linker Verteidiger | LV | Defensive Absicherung links |
| Rechter Mittelfeldspieler | RM | Verbindung Abwehr-Angriff rechts |
| Linker Mittelfeldspieler | LM | Verbindung Abwehr-Angriff links |
| Stürmer (Mitte) | ST | Tor-Abschluss, Pressung |
